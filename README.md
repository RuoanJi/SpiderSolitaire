# Spider Solitaire

Spider Solitaire for desktop and mobile browsers, styled after the Windows 7 game.

## Play

Open `index.html` in any modern browser. It's one self-contained file (all code,
styles and graphics inlined), so it works from a double-click, from GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root), or from any static host.

## Develop

Requires Node.js 20+.

```
npm install
npm run dev        # http://localhost:5173, rebuilds on every page load
npm test           # engine unit tests
npm run typecheck
npm run build      # regenerates index.html — commit it so GitHub Pages serves the update
```

Append `?ui=touch` or `?ui=desktop` to the URL to force the mobile or desktop UI.

## Layout

```
index.html       built game (generated by npm run build — don't edit by hand)
src/
  index.html     page template
  engine/        cards.ts, rng.ts, game.ts   pure game logic (rules, scoring, undo/redo, hints, save format)
  ui/            cardface.ts, layout.ts, dialogs.ts, fireworks.ts
  services/      storage.ts (settings, saved game, statistics), audio.ts (synthesized sounds)
  app.ts         controller: rendering, pointer/touch/keyboard input, menus and dialogs
  styles.css     look and feel
tests/           engine tests (node:test)
build.mjs        esbuild bundler that inlines JS + CSS into index.html
```

All card art and sounds are original; not affiliated with Microsoft.
